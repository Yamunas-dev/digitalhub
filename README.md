# DigitalHub – Electronics Store

Smart Technology. Better Living.

A React + Vite e-commerce demo (cart, favorites, search, filters, checkout, orders) using Context API and localStorage.

## Run in VS Code
1. Install Node.js 18+ from https://nodejs.org
2. Open this folder in VS Code (File > Open Folder)
3. Open the terminal (Ctrl + `) and run:

    npm install
    npm run dev

4. Open the URL shown (usually http://localhost:5173)

## Build for production
    npm run build
    npm run preview
